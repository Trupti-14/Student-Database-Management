🎓 Student Database Management

This project is developed in Java using Object-Oriented Programming (OOPs) concepts like classes, objects, constructors, and encapsulation.

It allows users to:
Input student details like roll number, name and marks in 5 subjects.
Calculate grade automatically out of 10.
Display students whose grade is greater than or equal to 8.

The project is implemented in two ways:
1. Using Arrays – Fixed number of students.
2. Using ArrayList – Dynamic input based on user choice.

Main focus: Encapsulation, Constructors, Data Handling, and Grade Calculation using Java.
